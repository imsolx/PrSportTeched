# รายงานวิเคราะห์ผู้ใช้งานและความสามารถของระบบ TECHED SPORT

## 1. ภาพรวมระบบ

ระบบ **TECHED SPORT / RMUTT Sports MVP** เป็นเว็บแอปพลิเคชันสำหรับบริหารการแข่งขันกีฬาและงานประชาสัมพันธ์ ตั้งแต่การกำหนดข้อมูลกีฬา การนำเข้านักศึกษา การจัดทีม การสร้างตารางแข่งขัน การบันทึกผล การเผยแพร่ข่าว ไปจนถึงการจัดทำรายงาน

ระบบไม่มีขั้นตอนสมัครทีม หรือนักกีฬาออนไลน์ นักศึกษา นักกีฬา ผู้ฝึกสอน และทีมเป็นข้อมูลที่เจ้าหน้าที่นำเข้าหรือจัดการจากระบบหลังบ้าน ไม่ใช่บัญชีผู้ใช้งานที่เข้าสู่ระบบด้วยตนเอง

---

## 2. กลุ่มผู้ใช้งานระบบ

ระบบแบ่งผู้ใช้งานออกเป็น 7 กลุ่ม รวมผู้เยี่ยมชม ดังนี้

| กลุ่มผู้ใช้ | รหัสบทบาท | หน้าที่และความสามารถหลัก |
|---|---|---|
| ผู้เยี่ยมชม | `guest` | ดูข้อมูลสาธารณะโดยไม่ต้องเข้าสู่ระบบ |
| Super Admin | `super_admin` | ใช้งานได้ทุกส่วน รวมถึงข้อมูลหลัก ผู้ใช้ คำเชิญ ฐานข้อมูล และการเผยแพร่รายงาน |
| Admin / เจ้าหน้าที่กลาง | `admin` | บริหารข้อมูลหลัก งานทะเบียนนักกีฬา ผู้ใช้ การแข่งขัน ข่าว งาน และรายงาน |
| หัวหน้ากีฬา | `sport_head` | บริหารทัวร์นาเมนต์ ทีม สมาชิกทีม ตารางแข่งขัน ผลการแข่งขัน งาน และรายงาน |
| กรรมการบันทึกผล | `result_officer` | ควบคุมการแข่งขัน บันทึกคะแนน เวลา และเหตุการณ์ พร้อมจัดทำรายงาน |
| ฝ่ายประชาสัมพันธ์ | `public_relations` | สร้างและเผยแพร่ข่าว สร้างแบนเนอร์ ใช้ AI ช่วยร่างข่าว งาน และรายงาน |
| ผู้บริหาร / ผู้ดูข้อมูล | `viewer` | ดูแดชบอร์ดและรายงาน ดาวน์โหลดรายงาน แต่ไม่มีสิทธิ์แก้ไข |

> **หมายเหตุ:** นักศึกษา นักกีฬา กัปตัน ตัวสำรอง และผู้ฝึกสอนเป็นข้อมูลสมาชิกทีม ไม่ได้มีบัญชีเข้าใช้ระบบของตนเอง

## 3. ความสามารถแยกตามบทบาท

### 3.1 ผู้เยี่ยมชม

- ดูหน้าแรกและข้อมูลสรุป
- ดูรายการกีฬาที่เปิดใช้งาน
- ค้นหานักกีฬาตามคณะ สาขา กีฬา และทีม
- ดูตารางแข่งขัน
- ดูผลการแข่งขัน
- ดูตารางคะแนน
- อ่านข่าวที่เผยแพร่แล้ว
- ดู Hall of Fame

### 3.2 Super Admin

- ใช้งานฟีเจอร์หลังบ้านทั้งหมด
- จัดการข้อมูลกีฬา กติกา และโครงสร้างหน่วยงาน
- จัดการนักศึกษา ทีม สมาชิกทีม ทัวร์นาเมนต์ และแมตช์
- บันทึกผลการแข่งขันและเหตุการณ์
- จัดการข่าว แผนงาน ผู้ใช้ และคำเชิญ
- สร้าง แก้ไข เผยแพร่ และลบรายงาน
- ตรวจสอบข้อมูลการเชื่อมต่อฐานข้อมูล

### 3.3 Admin / เจ้าหน้าที่กลาง

- มีสิทธิ์ใช้งานหลักเกือบเท่า Super Admin
- จัดการข้อมูลหลักทั้งหมด
- เพิ่ม แก้ไข ลบ และนำเข้าข้อมูลนักศึกษา รวมถึงรูปประจำตัว
- ตรวจข้อมูล CSV และจัดการข้อมูลทีม/สมาชิกทีม
- จัดการผู้ใช้และคำเชิญ
- จัดการการแข่งขัน ข่าว งาน และรายงาน
- เผยแพร่และลบรายงานได้

### 3.4 หัวหน้ากีฬา

- ดูแดชบอร์ด
- ดูข้อมูลกีฬา กติกา และหน่วยงาน
- สร้างและแก้ไขทัวร์นาเมนต์
- เลือกกีฬาและกติกาที่ใช้ในรายการ
- กำหนดสาขาที่เข้าร่วม
- สร้างทีมและจัดสมาชิกทีม
- สร้างและแก้ไขตารางแข่งขัน
- บันทึกผลและเหตุการณ์การแข่งขัน
- จัดการแผนงาน
- สร้างและแก้ไขรายงาน
- ไม่มีสิทธิ์จัดการบัญชีผู้ใช้
- ไม่มีสิทธิ์เผยแพร่หรือลบรายงาน

### 3.5 กรรมการบันทึกผล

- ดูแดชบอร์ดและข้อมูลการแข่งขัน
- ดูทีม แมตช์ และตารางคะแนน
- เริ่ม หยุด และปรับนาฬิกาการแข่งขัน
- บันทึกคะแนนและผลการแข่งขัน
- บันทึกเหตุการณ์ เช่น การทำคะแนน ฟาวล์ ใบเหลือง และใบแดง
- ยกเลิกเหตุการณ์ที่บันทึกผิด
- จัดการแผนงาน
- สร้างและแก้ไขรายงาน
- ไม่มีสิทธิ์สร้างหรือลบกีฬา ทัวร์นาเมนต์ ทีม และแมตช์

### 3.6 ฝ่ายประชาสัมพันธ์

- ดูแดชบอร์ดและข้อมูลการแข่งขัน
- สร้าง แก้ไข เผยแพร่ และลบข่าว
- เชื่อมข่าวกับกีฬา ทัวร์นาเมนต์ ทีม และแมตช์
- อัปโหลดรูปปกข่าว
- ใช้ AI ช่วยร่างข่าว
- ใช้ Banner Studio ออกแบบภาพปก
- จัดการแผนงาน
- สร้างและแก้ไขรายงาน
- ไม่มีสิทธิ์จัดการข้อมูลผู้ใช้หรือข้อมูลหลัก

### 3.7 ผู้บริหาร / ผู้ดูข้อมูล

- ดูแดชบอร์ด
- ดูรายการรายงาน
- เปิดดูและดาวน์โหลดรายงาน
- ไม่มีสิทธิ์สร้าง แก้ไข ลบ หรือเผยแพร่รายงาน
- ไม่มีสิทธิ์แก้ไขข้อมูลการแข่งขัน

## 4. รายละเอียดความสามารถรายฟีเจอร์

### 4.1 เว็บไซต์สาธารณะ

ทุกคนสามารถใช้งานได้โดยไม่ต้องเข้าสู่ระบบ

- หน้าแรกแสดงจำนวนกีฬา ตารางใกล้ถึง ผลล่าสุด ข่าวล่าสุด และ Hall of Fame
- แสดงเฉพาะกีฬาที่เปิดใช้งาน
- แสดงเฉพาะทัวร์นาเมนต์ที่ไม่ใช่สถานะร่างหรือยกเลิก
- ค้นหานักกีฬาตามลำดับ คณะ → สาขา → กีฬา → ผู้เล่น
- ค้นหาด้วยชื่อผู้เล่น รหัสนักศึกษา หรือชื่อทีม
- ดูตารางแข่งขันโดยกรองตามทัวร์นาเมนต์
- ดูผลการแข่งขันและตารางคะแนน
- อ่านเฉพาะข่าวที่มีสถานะเผยแพร่แล้ว

### 4.2 แดชบอร์ด

- แสดงจำนวนกีฬาที่เปิดใช้งาน
- แสดงจำนวนทีมที่อนุมัติ
- แสดงจำนวนนักศึกษา
- แสดงจำนวนแมตช์ที่จบแล้ว
- แสดงจำนวนงานค้างและงานเกินกำหนด
- แสดง Audit Log หรือกิจกรรมล่าสุด
- แสดงงานที่กำลังจะถึง
- ใช้ AI สรุปสถานการณ์และงานสำคัญ

### 4.3 ข้อมูลกีฬาและกติกา

- เพิ่ม แก้ไข เปิด/ปิด และลบชนิดกีฬา
- กำหนดกีฬาประเภททีมหรือรายบุคคล
- กำหนดเพศ จำนวนผู้เล่นขั้นต่ำ สูงสุด และตัวสำรอง
- กำหนดไอคอน โลโก้ และกติกาย่อ
- สร้างกติกาหลายเวอร์ชันต่อกีฬา
- กำหนดระบบคะแนนแบบคะแนนรวม เซต เวลา หรืออันดับ
- กำหนดจำนวนช่วงหรือเซต และเวลาต่อช่วง
- กำหนดการต่อเวลาและวิธีตัดสินกรณีเสมอ
- กำหนดคะแนนสะสมสำหรับชนะ เสมอ และแพ้
- กำหนดประเภทเหตุการณ์ เช่น คะแนน ฟาวล์ ใบเหลือง และใบแดง

### 4.4 โครงสร้างหน่วยงาน

- จัดการข้อมูลมหาวิทยาลัย
- จัดการข้อมูลคณะ
- จัดการข้อมูลสาขา
- กำหนดรหัส ชื่อ และต้นสังกัด
- อัปโหลดโลโก้หน่วยงาน
- เปิดหรือปิดการใช้งานหน่วยงาน

### 4.5 ทะเบียนนักศึกษา

- เพิ่ม แก้ไข และลบนักศึกษา
- จัดเก็บรหัสนักศึกษา คำนำหน้า ชื่อ นามสกุล และสาขา
- จัดเก็บปีเข้า เพศ และโทรศัพท์
- อัปโหลดหรือกำหนด URL รูปประจำตัว
- กรองข้อมูลตามคณะ สาขา และกีฬา
- นำเข้ารายชื่อจาก CSV
- ตรวจสอบ CSV ก่อนนำเข้า
- ป้องกันรหัสนักศึกษาซ้ำ
- ไม่อนุญาตให้ลบนักศึกษาที่ถูกเพิ่มเข้าเป็นสมาชิกทีมแล้ว

### 4.6 จัดการทัวร์นาเมนต์

ระบบกำหนดกระบวนการทำงานไว้ 11 ขั้นตอน

1. สร้างข้อมูลทัวร์นาเมนต์
2. เลือกกีฬาที่จัด
3. เลือกชุดกติกาของแต่ละกีฬา
4. กำหนดสาขาที่เข้าร่วม
5. นำเข้าข้อมูลนักศึกษา
6. สร้างทีม
7. จัดสมาชิกทีม
8. ตรวจความพร้อม
9. สร้างตารางแข่งขัน
10. บันทึกผลและเหตุการณ์
11. จัดทำข่าวและรายงาน

ข้อมูลที่สามารถกำหนดได้ประกอบด้วยชื่อรายการ ปีการศึกษา วันเริ่มและสิ้นสุด สถานะ โลโก้ กีฬาที่จัด และกติกาที่ใช้

### 4.7 ทีมและสมาชิกทีม

- สร้างทีมโดยเชื่อมกับทัวร์นาเมนต์ กีฬา และสาขา
- กำหนดชื่อและโลโก้ทีม
- ระบุกัปตันทีม
- เปลี่ยนสถานะทีม เช่น `submitted`, `approved`, `rejected` และ `locked`
- บันทึกเหตุผลการไม่อนุมัติ
- เพิ่มสมาชิกด้วยรหัสนักศึกษา
- กำหนดบทบาท `player`, `captain`, `coach` หรือ `substitute`
- ระบุเบอร์เสื้อและตำแหน่งผู้เล่น
- นำเข้าสมาชิกจาก CSV
- ตรวจสอบสมาชิกซ้ำและเงื่อนไขตามกติกา
- ไม่อนุญาตให้ลบทีมที่ถูกใช้ในแมตช์แล้ว

### 4.8 ตารางแข่งขันและศูนย์ควบคุมแมตช์

- สร้างคู่แข่งขัน
- กำหนดรอบ สนาม วันที่ และเวลา
- กำหนดสถานะแมตช์เป็น `scheduled`, `live`, `completed`, `cancelled` หรือ `postponed`
- ควบคุมนาฬิกาและช่วงการแข่งขัน
- บันทึกเหตุการณ์โดยระบุทีม นักกีฬา นาที และประเภทเหตุการณ์
- คำนวณคะแนนจากเหตุการณ์
- ยกเลิกเหตุการณ์ที่บันทึกผิดโดยเก็บประวัติผู้ดำเนินการ
- บันทึกคะแนนสุดท้าย
- ระบุผู้ชนะกรณี Tie-break
- คำนวณตารางคะแนนใหม่อัตโนมัติ
- แสดงแข่ง ชนะ เสมอ แพ้ คะแนนได้ คะแนนเสีย ผลต่าง และอันดับ

### 4.9 ข่าวและประชาสัมพันธ์

- สร้าง แก้ไข เผยแพร่ และลบข่าว
- แบ่งข่าวเป็นข่าวทั่วไป ข่าวหน่วยงาน และ Hall of Fame
- เชื่อมข่าวกับกีฬา ทัวร์นาเมนต์ ทีม และแมตช์
- อัปโหลดรูปปกหรือใช้ URL รูปภาพ
- ปักหมุดข่าว
- ใช้ AI สร้างร่างข่าวจากข้อมูลการแข่งขัน
- เลือกรูปแบบข่าวผลการแข่งขัน ข่าวก่อนแข่งขัน หรือไฮไลต์
- เลือกน้ำเสียงทางการ เร้าใจ หรือสร้างแรงบันดาลใจ

#### Banner Studio

- เลือกแม่แบบภาพประชาสัมพันธ์
- อัปโหลดรูปการแข่งขัน
- ปรับสีและการจัดวาง
- ปรับขนาดและตำแหน่งรูป
- ปรับตำแหน่งชื่อกีฬา หัวเรื่อง และรายละเอียด
- ลากข้อความบน Canvas
- ดาวน์โหลดเป็น PNG
- ใช้ภาพที่ออกแบบเป็นรูปปกข่าวทันที

### 4.10 แผนงานและการมอบหมายงาน

- สร้างและแก้ไขงาน
- กำหนดประเภทงาน เช่น รายงาน ข่าว หรือการแข่งขัน
- กำหนดความสำคัญและวันครบกำหนด
- มอบหมายงานให้บัญชีผู้ใช้
- เชื่อมงานกับทัวร์นาเมนต์ ทีม แมตช์ ข่าว หรือรายงาน
- เปลี่ยนสถานะเป็น `todo`, `doing`, `blocked` หรือ `done`
- แสดงงานในรูปแบบบอร์ดและตาราง
- บันทึกเวลาที่งานเสร็จ

### 4.11 ผู้ใช้และคำเชิญ

- เพิ่มและแก้ไขบัญชีผู้ใช้
- เปิดหรือปิดการใช้งานบัญชี
- กำหนดบทบาท สาขา และกีฬาที่รับผิดชอบ
- ป้องกันผู้ดูแลปิดใช้งานหรือลบบัญชีของตนเอง
- สร้างลิงก์คำเชิญ
- กำหนดวันหมดอายุและจำนวนครั้งที่ใช้คำเชิญได้
- ยกเลิกคำเชิญ
- ให้ผู้รับคำเชิญตั้งชื่อและรหัสผ่านด้วยตนเอง
- ให้ผู้ใช้แก้ไขโปรไฟล์และรหัสผ่านของตนเอง

ระบบไม่มีหน้าสมัครบัญชีแบบสาธารณะ บัญชีต้องถูกสร้างหรือได้รับคำเชิญจากผู้ดูแล

### 4.12 รายงาน

ผู้ใช้หลังบ้านทุกบทบาทสามารถดูและดาวน์โหลดรายงานได้ แต่บทบาท Viewer อ่านอย่างเดียว

ความสามารถของระบบรายงาน ได้แก่

- สร้างและแก้ไขรายงาน
- เลือกหมวดหมู่และแบบฟอร์ม
- เชื่อมข้อมูลจากทัวร์นาเมนต์
- ดึงจำนวนกีฬา ทีม นักกีฬา และผลการแข่งขันอัตโนมัติ
- บันทึกหลักการ ผลดำเนินงาน ผลกีฬา KPI งบประมาณ และผลลัพธ์
- บันทึกปัญหาและข้อเสนอแนะ
- แนบรูปภาพ PDF Word หรือเอกสารประกอบ
- ใช้ AI ช่วยร่างข้อความลงในแบบฟอร์ม
- เปลี่ยนสถานะ `draft` → `review` → `completed` → `published`
- Export เป็น HTML, Word `.doc` และ JSON

เฉพาะ Super Admin และ Admin เท่านั้นที่สามารถเผยแพร่และลบรายงาน

#### หมวดหมู่รายงาน

1. รายงานประชาสัมพันธ์ผลการแข่งขันกีฬา
2. รายงานประชาสัมพันธ์โครงการหรือกิจกรรมกีฬา
3. รายงานภาพรวมงานประชาสัมพันธ์กีฬา
4. รายงานตัวชี้วัดงานประชาสัมพันธ์กีฬา
5. รายงานสรุปประชาสัมพันธ์กีฬาสำหรับผู้บริหาร
6. รายงานงบประมาณงานประชาสัมพันธ์กีฬา
7. รายงานการมีส่วนร่วมและการรับรู้ด้านกีฬา
8. รายงานประเด็นสื่อสาร ปัญหา และข้อเสนอแนะด้านกีฬา

ระบบมีแบบฟอร์มรายงานย่อยทั้งหมด 17 แบบ เช่น สรุปผลการแข่งขัน รายงานรางวัล ผลงานแยกตามกีฬา รายงานโครงการ KPI สรุปผู้บริหาร รายงานประจำปี งบประมาณ และรายงานปัญหา

## 7. ประเด็นที่พบจากการวิเคราะห์สิทธิ์

### 7.1 แดชบอร์ดของ Viewer

หน้าจออนุญาตให้ Viewer เปิดแดชบอร์ด แต่ API แดชบอร์ดเรียกข้อมูลแผนงานผ่าน `listTasks()` ซึ่งไม่อนุญาตบทบาทนี้ ทำให้แดชบอร์ดอาจโหลดไม่สำเร็จทั้งหน้า

**ข้อเสนอแนะ:** แยกข้อมูลแผนงานออกจาก Dashboard API หรือเพิ่มสิทธิ์อ่านงานให้ Viewer ตามความเหมาะสม

### 7.2 เมนูทีมถูกซ่อนทุกบทบาท

ใน HTML มีเมนูและหน้าจัดการทีม แต่รายการหน้าที่อนุญาตของแต่ละบทบาทไม่มีค่า `teams` ทำให้เมนูทีมถูกซ่อนทุกบทบาท การจัดทีมจึงต้องเข้าผ่านพื้นที่จัดการทัวร์นาเมนต์

**ข้อเสนอแนะ:** หากต้องการใช้หน้าแยก ควรเพิ่ม `teams` ให้ Super Admin, Admin และหัวหน้ากีฬา หรือถ้าไม่ใช้แล้วควรถอดเมนูและหน้าที่ซ้ำซ้อนออก

### 7.3 หน้าข้อมูลหลักของหัวหน้ากีฬา

หัวหน้ากีฬาเห็นหน้าข้อมูลหลัก แต่ API อนุญาตให้บันทึกกีฬา กติกา และหน่วยงานเฉพาะ Super Admin และ Admin

**ข้อเสนอแนะ:** ซ่อนฟอร์มและปุ่มแก้ไขสำหรับหัวหน้ากีฬา แล้วแสดงเป็นโหมดอ่านอย่างเดียว หรือปรับสิทธิ์ API ให้สอดคล้องกับหน้าที่จริง

### 7.4 หน้าทัวร์นาเมนต์ของกรรมการบันทึกผล

กรรมการบันทึกผลเห็นหน้าทัวร์นาเมนต์และแบบฟอร์มบางส่วน แต่ API อนุญาตเฉพาะการบันทึกผล นาฬิกา และเหตุการณ์ ไม่อนุญาตให้สร้างหรือแก้ไขแมตช์

**ข้อเสนอแนะ:** ซ่อนปุ่มสร้าง แก้ไข และลบแมตช์สำหรับบทบาทนี้ โดยคงเฉพาะ Match Center และส่วนบันทึกผล

## 8. สรุป

ระบบครอบคลุมวงจรการบริหารการแข่งขันกีฬาค่อนข้างครบ ตั้งแต่ข้อมูลตั้งต้น การจัดทัวร์นาเมนต์ การจัดทีม การแข่งขัน การประชาสัมพันธ์ ไปจนถึงรายงานสำหรับผู้บริหาร โดยมีการแบ่งหน้าที่ตามบทบาทอย่างชัดเจนในระดับ API

ก่อนนำไปใช้งานจริงกับผู้ใช้หลายบทบาท ควรปรับความสอดคล้องระหว่างเมนูหน้าจอและสิทธิ์ API ในประเด็นที่ระบุไว้ เพื่อป้องกันกรณีผู้ใช้เห็นเมนูแต่ใช้งานไม่ได้ หรือมีความสามารถใน API แต่เข้าถึงจากหน้าจอไม่ได้

- `database/seed.mysql.sql` — หมวดหมู่และแบบฟอร์มรายงานเริ่มต้น
